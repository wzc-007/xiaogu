排队详情本地演示页

1. 电脑预览
   双击 index.html，可直接在浏览器打开。

2. 手机本地打开（最简单）
   把整个 queue-page 文件夹发送到手机，使用手机浏览器或文件管理器打开 index.html。

3. 手机访问电脑上的页面
   在本文件夹打开 PowerShell，运行：
   python -m http.server 8080
   然后让手机和电脑连接同一个 Wi-Fi，在手机浏览器访问：
   http://电脑的局域网IP:8080

页面功能
- 北京时间每秒更新。
- 点击右下角“修改”，可改“我的号码”“当前叫号”“每桌平均用时”“取号时间”。
- 保存后，前方桌数、等待时长、预计叫号时间、已等待时间和进度条自动联动。
- 设置保存在当前浏览器本地，刷新页面不会丢失。
- 页面不连接商家系统，仅用于本地界面演示和个人时间估算。
